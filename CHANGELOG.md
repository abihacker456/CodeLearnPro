All notable changes to CodeLearn Pro will be documented in this file.

## [1.0.1] - 2026-10-03

### Added
- In-app privacy policy link on the About Developer screen (required by Google Play policy)

### Changed
- Minor stability improvements

## [1.0.0] - 2026-10-01

### Added
- 25 structured lessons across five languages: Python, C++, Kotlin, Java, and JavaScript
- Built-in code editor with real code execution via Judge0 CE
- Practice exercise after every lesson
- Progress tracking across all languages
- Bookmark system for saving lessons
- Search across all lessons
- Light and dark theme support
- About Developer screen
- Contact Support screen
- Reset progress option

### Known Issues
- Deobfuscation mapping file not yet uploaded to Play Console (crash reports may be harder to read)
